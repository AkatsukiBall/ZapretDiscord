## ⚙️ Подготовка и запуск

1. Сначала активируйте безопасный DNS (Secure DNS).
   * В Chrome включите пункт "Использовать безопасный DNS" и выберите провайдера, отличного от "Поставщик по умолчанию".
   * В Firefox откройте настройки "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и укажите URL вручную. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
   * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. Инструкция доступна [по этой ссылке](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 рекомендуется использовать именно этот способ.
   * Владельцам роутеров Keenetic необходимо включить параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Скачайте zip- или rar-архив со [страницы последнего релиза](https://github.com/AkatsukiBall/zapret-discord-youtube/releases/latest).

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг можно не выполнять.

4. Распакуйте архив в каталог, в пути к которому нет кириллических символов и специальных знаков.

5. Запустите подходящий скрипт.
   * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`.
   * Для добавления выбранной стратегии в автозапуск используйте **`service.bat`** → `Install Service` → выберите нужную стратегию.

## ℹ️ Назначение основных файлов и пунктов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии, включая ALT, FAKE и другие, пока не найдёте подходящую именно для вашей системы**.

- [**`service.bat`**](./service.bat) — управление автозапуском, фильтрами, обновлениями и диагностикой:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск через `services.msc`.</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из списка служб.
  - **`Check Status`** — посмотреть состояние обхода и служб, включая запущенную стратегию и WinDivert.
  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, использующих UDP и TCP-порты выше 1023.  
    **После смены значения стратегию необходимо перезапустить.**  
    Значение в скобках показывает текущий статус: включено или выключено.
  - **`IPSet Filter`** — изменить режим обработки сервисов из `ipset-all.txt`.  
    Опция полезна при проверке ресурса, который без zapret работает, а с ним — нет.  
    В скобках отображается состояние:
    - `none` — IP-адреса не проходят проверку;
    - `loaded` — проверяются только IP из списка;
    - `any` — под фильтр попадает любой IP.
  - **`Auto-Update Check`** — включить или отключить автоматический поиск обновлений.
  - **`Replace active fakes`** — заменить текущий используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** — загрузить актуальную версию `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновить hosts-файл <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord</ins>.
  - **`Check for Updates`** — вручную проверить наличие обновлений.
  - **`Run Diagnostics`** — найти распространённые причины, из-за которых zapret может не запускаться или не работать.  
    В конце процедуры можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного отказа приложения.
  - **`Run Tests`** — открыть проверку стратегий:
    - `Standard tests` — тестирование сайтов из `utils/targets.txt`;
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен открыться `winws.exe`. Его можно заметить среди запущенных программ на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/AkatsukiBall/zapret-discord-youtube/issues/522).

### Ни одна стратегия не запускается или не подходит

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts-файл окажется устаревшим, программа предложит обновить его вручную:  
  - скопируйте весь текст из открывшегося блокнота;
  - от имени администратора откройте текстовым редактором файл `hosts` в созданной папке;
  - вставьте скопированное содержимое в конец `hosts` или замените ранее добавленные аналогичные строки;
  - сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно были сохранены.

#### Работа этого способа не гарантируется. Если он не помог, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) вместе с [локальным прокси](https://github.com/AkatsukiBall/tg-ws-proxy) или любым публичным прокси.

### Обход не работает или перестал работать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Со временем обнаруженная стратегия может перестать помогать. В репозитории доступно много вариантов обхода; если готовые конфигурации не подходят, можно создать собственную на основе одной из них и изменить параметры.
> Описание параметров находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` → `Run Diagnostics`.
- Убедитесь, что нужный адрес присутствует в списке доменов или IP-адресов.
- Протестируйте другие варианты, например **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/AkatsukiBall/zapret-discord-youtube/issues/765).

### Как полностью переустановить или обновить сборку?

- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите компьютер.
- Откройте `service.bat` → `Remove Services`.
- Запустите `service.bat` → `Run Diagnostics`; при обнаружении ошибок исправьте их и в конце подтвердите действие клавишей Y.
- Удалите старую папку zapret.
- Скачайте свежую версию со [страницы релизов](https://github.com/AkatsukiBall/zapret-discord-youtube/releases) — архив вида `zapret-discord-youtube-...`.
- Нажмите правой кнопкой мыши на архиве, откройте свойства и, если в нижней части окна есть флажок разблокировки, включите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска. В пути не должно быть пробелов и специальных символов.
- По очереди попробуйте разные `general`-скрипты. Проверяйте нужные интернет-ресурсы; если они не работают, закройте программу через значок замка на панели задач и запустите другую стратегию.
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` → `Install Service` → выберите стратегию.

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### В Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё присутствует в службах

1. Узнайте имя службы в командной строке Windows. Нажмите Win+R, введите `cmd`, затем выполните:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу, подставив её имя вместо `название_из_первого_шага`:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не загружается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8F-подготовка-и-запуск).
- Отключите блокировщик рекламы: известно, что YouTube начал активно с ними бороться.
- Если раньше всё работало, поочерёдно испытайте остальные стратегии.
- Дополнительные сведения: [#251](https://github.com/AkatsukiBall/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8F-подготовка-и-запуск).
- Сначала определите стратегию, на которой открывается YouTube, и запустите её.
- В `service.bat` перейдите в `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте работу приложения после очистки.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия доступна, можно временно пользоваться ей.
- Если Discord не работает и в браузере, повторно проверьте все стратегии: YouTube и Discord могут открываться на разных вариантах.
- См. также [#252](https://github.com/AkatsukiBall/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/AkatsukiBall/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не подключаются игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

В качестве универсального варианта попробуйте:
- обновить ipset через `service.bat` и включить `Game Filter`;
- если это не помогло, дополнительно включить `ipset any`.

Учтите: режим `ipset any` способен нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Лучше выяснить IP-адреса, которые использует игра, и добавить их в `ipset-all.txt`.

Если способ не сработал, создайте тему в разделе [Discussions](https://github.com/AkatsukiBall/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет моей проблемы

- Оформите обращение [здесь](https://github.com/AkatsukiBall/zapret-discord-youtube/issues).

## 🗒️ Как добавить адреса других ресурсов

Расширить список адресов для обхода можно с помощью следующих файлов:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например если IP-сеть присутствует в `ipset-all.txt`, но конкретный домен из неё фильтровать не следует;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети-исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
